# Research Provenance

The original 2024 material contains two biomedical data expansion ideas, inference scripts, prompt examples, data cleaning code and observations about repetition and truncated outputs. It does not establish a completed biomedical fine tuning experiment or a downstream performance improvement.

The October 2026 implementation adds source ID preservation, a fixed PQA-L evaluation boundary, structured prompts, local and API teacher interfaces, request caching, source quote checks, explicit review records and supervised data construction. Optional LoRA training and evaluation commands are reader references. These additions must be described as reconstruction and follow-up work when presenting the project.

The owner has chosen a method and augmentation prototype release. Student training and downstream comparisons are optional reader work, not required experiments for this release. The 2026 demonstration consists of twenty assistant-authored QA examples from ten training sources, composed and source-reviewed in the project conversation. It does not represent a 2024 dataset, an external API experiment, independent expert review or a student-training result.

The old expansion data with 39,612 records contains three generic question templates and prefix-transformed original answers. It is retained only in the separate local archive and is not evidence of successful generation in this project.

The archive's MetaMath main generation files and DPO training files match upstream reference implementations. The DPO experiment configuration uses HH-RLHF. Those files are not copied into the new project as personal implementation, and the old HH runs are not represented as biomedical training results.

The release separates project implementation from upstream methods and data. No project-specific code license has been selected. Existing datasets, model weights and upstream packages retain their own terms.
